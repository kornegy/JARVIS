# JARVIS — Дорожная карта

Сложность: **S** — до 1 недели, **M** — 1–2 недели, **L** — 2–4 недели, **XL** — больше
(оценка для одного разработчика-ассистента с проверкой на реальном Mac).

Правило: следующий этап начинается, только когда предыдущий **работает** — собран, протестирован
в CI и проверен на реальном Mac пользователя (то, что CI проверить не может, перечислено в
«Проверка на устройстве»).

## Минимальный MVP

MVP = Phase 1 + Phase 2 + ядро Phase 3:

* menu bar приложение, включение/выключение, пауза микрофона, индикатор состояния;
* wake word «Привет, Джарвис» и Push-to-Talk, локальное распознавание (RU/EN);
* локальные правила для ~20 частых команд: приложения (открыть/закрыть/переключить),
  поиск файлов (по имени, типу, дате, «последний скачанный PDF»), громкость, время/дата,
  открыть сайт/поиск в браузере, «что ты умеешь»;
* голосовой ответ с характером;
* реестр инструментов, подтверждения, журнал аудита, Permission Manager;
* полностью офлайн, без LLM.

LLM (локальная и облачная), память, автоматизации — после MVP.

## Фазы

### Phase 0 — Research & Architecture · S · ✅ завершена
Документы: Architecture, TechnologyComparison, Security, Privacy, Roadmap, PerformanceTargets.

### Phase 1 — Project Foundation · M · 🔄 в работе
* репозиторий, структура, SPM-пакет `JarvisKit` + XcodeGen-проект, Makefile;
* CI на macOS (GitHub Actions): тесты пакета, сборка приложения, UI-тест запуска, privacy-lint;
* menu bar приложение (агент без иконки в Dock), мини-окно, окно журнала, Settings;
* настройки: модель, хранение в JSON, миграции, резервные копии;
* privacy-safe логирование, журнал аудита;
* архитектурные интерфейсы: состояния, протоколы движков, `Tool`/`ToolRegistry`,
  валидация аргументов, политика подтверждения;
* базовые тесты.

**Готово, когда:** CI зелёный; приложение собирается, запускается, показывает статус;
на Mac пользователя — запускается из Xcode/`make run`.

### Phase 2 — Voice MVP · L
* `JarvisVoice`: AVAudioEngine с voice processing, RMS-гейт, `SpeechDetector`,
  `SpeechTranscriber`/`DictationTranscriber`, проверки языков и скачивание моделей;
* wake word (настраиваемые фразы), PTT (глобальная горячая клавиша), окончание фразы по паузе;
* TTS (`AVSpeechSynthesizer`): голос, скорость, громкость;
* `JarvisAI` v1: `RuleIntentParser` (RU/EN), шаблоны ответов с личностью;
* оркестратор `AssistantController`, индикатор микрофона, звуки начала/конца прослушивания;
* текстовый ввод команд (та же цепочка) — для тихих мест и отладки;
* замеры: CPU/RAM в простое и при прослушивании.

**Проверка на устройстве:** качество русского, ложные срабатывания wake word, CPU при речи рядом.

### Phase 3 — macOS Control · L
* `JarvisMac`: адаптеры приложений, окон (AX), файлов (Spotlight + FileManager),
  системы (громкость, Wi-Fi, информация), браузера, Shortcuts (белый список), буфера обмена;
* Permission Manager с UI статусов и объяснениями;
* исполнитель плана, подтверждения (голос/кнопка/⏎), журнал отмены, «Джарвис, отмени»;
* политика путей и приложений.

### Phase 4 — Personal Assistant · XL
* `JarvisAI` v2: провайдеры Apple Foundation Models, OpenAI-совместимый (Ollama/LM Studio/
  OpenAI), Anthropic; `HybridRouter`; окно согласия; ключи в Keychain;
* `JarvisMemory`: предпочтения, привычки, пользовательские инструкции; UI просмотра/удаления;
  запрет категорий; выключатель персонализации;
* `JarvisAutomation`: сценарии (голосовые фразы, время, запуск Mac), редактор, история;
* почта (Mail): непрочитанные, сводка (локально или с согласием в облако);
* календарь и напоминания (EventKit);
* предложения автоматизировать повторяющиеся последовательности.

### Phase 5 — Optimization & Security · M
* профилирование (Instruments: Time Profiler, Allocations, Energy Log), сравнение с целями;
* при необходимости — двухступенчатый wake word (Core ML KWS);
* security review, fuzz-тесты валидатора, проверка офлайн-режима, регрессия.

### Phase 6 — Release · M
* Release-сборка, DMG, иконка, `CHANGELOG`, release notes, SemVer;
* Sparkle 2 + appcast на GitHub Releases, EdDSA-ключи;
* подготовка к Developer ID и нотаризации (скрипты; выполнение — после решения пользователя);
* резервные копии и миграции данных, процедура отката.

## Решения, которые нужны от пользователя

| Когда | Вопрос | Рекомендация |
|---|---|---|
| сейчас | версия macOS на твоём Mac (нужна 26+) | — |
| до Phase 2 | основной язык общения (RU, EN, оба) | RU + EN |
| до Phase 4 | локальная LLM: Apple Foundation Models (если поддерживает язык) и/или Ollama/LM Studio (отдельное приложение, +2–3 ГБ на модель) | Apple FM + Ollama с Qwen3 4B |
| до Phase 4 | нужен ли облачный AI и какой провайдер (платно, нужен API-ключ) | Claude, режим Hybrid, подтверждение каждого запроса |
| до Phase 6 | Apple Developer Program ($99/год) для Developer ID и нотаризации | не обязательно для личного использования; для раздачи другим — нужен |

## Риски проекта

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Русский язык в Apple STT хуже ожидаемого | средняя | высокое | `DictationTranscriber`; план «Б» — WhisperKit (локально) |
| Apple Foundation Models не поддерживает русский | высокая | среднее | правила + Ollama; облако по согласию |
| CPU wake word при постоянной речи рядом | средняя | среднее | двухступенчатый KWS, режим «только PTT», расписание |
| Ложные срабатывания wake word | средняя | среднее | чувствительность, подтверждения, безвредная категория 1 |
| Хрупкость Apple Events-адаптеров | высокая | низкое | изоляция в адаптерах, тесты, понятные ошибки |
| Нет compiler/macOS в среде разработки ассистента | факт | среднее | вся сборка и тесты — в CI на macOS; ручная проверка на Mac пользователя |
| Сброс разрешений TCC при ad-hoc подписи | высокая | среднее | подпись бесплатным сертификатом Apple Development (см. Development.md) |
| Изменения API Apple (новые фреймворки) | средняя | среднее | адаптеры за протоколами, `#available` |

## Дополнительные возможности (предложения)

1. **Текстовый ввод** в мини-окне (⌘⇧J) — та же цепочка, когда говорить неудобно.
2. **«Покажи план»** — режим, где JARVIS озвучивает/показывает план перед выполнением.
3. **Тревожная кнопка** — глобальная клавиша: мгновенно выключить микрофон и отменить действия.
4. **Режим «только текст»** для ответов, когда рядом люди (или по календарю — во время встреч).
5. **App Intents** — действия JARVIS доступны в Shortcuts и Spotlight.
6. **Адаптеры IDE**: Rider/JetBrains, Xcode, VS Code — «открой проект X», «продолжи работу»
   (последний открытый проект).
7. **Экспорт/импорт** памяти и сценариев в JSON — данные принадлежат пользователю.
8. **Самодиагностика** в «О программе»: текущие RAM/CPU JARVIS, статус моделей и разрешений.
9. **Автоопределение языка** по wake word («Привет, Джарвис» → RU, «Hey Jarvis» → EN).
10. **Декларативные «навыки»** (JSON-сценарии без кода) для расширения без программирования.
