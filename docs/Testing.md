# JARVIS — Тестирование

Правило: не считаем «работает», пока это не проверено. Успешная компиляция — не доказательство.

## 1. Уровни

| Уровень | Инструмент | Где | Что проверяет | Статус |
|---|---|---|---|---|
| Unit | Swift Testing (`swift test`) | CI macOS, локально | логика модулей без UI и системных API | ✅ Phase 1 |
| Security | Swift Testing + privacy-lint | CI | политика подтверждения, валидатор аргументов, реестр, запрещённые API | ✅ Phase 1 |
| Privacy | Swift Testing + privacy-lint | CI | `Utterance`/`Sensitive` не раскрываются, логгер не пишет текст ошибок, аудит без деталей, приватные значения по умолчанию | ✅ Phase 1 |
| UI | XCUITest | CI macOS, локально | запуск, статус, включение/выключение, индикатор микрофона | ✅ Phase 1 (базовый) |
| Integration | Swift Testing с фейковыми движками | CI | оркестратор: wake word / PTT → распознавание → правило → инструмент → журнал → ответ | ✅ Phase 2 |
| Performance | XCTest `measure` + Instruments | Mac пользователя | RAM/CPU/задержки по [PerformanceTargets.md](PerformanceTargets.md) | Phase 2, 5 |
| Regression | весь набор в CI на каждый push | CI | ничего не сломалось | ✅ с Phase 1 |
| Manual | чек-листы ниже | Mac пользователя | то, что нельзя проверить в CI (микрофон, TCC, голос) | каждая фаза |

## 3. Запуск

```bash
make test
```

```bash
make test-ui
```

UI-тесты при первом запуске попросят разрешить Xcode/тест-раннеру управление компьютером
(Accessibility) — это нужно XCUITest, а не JARVIS.

Если UI-тест падает с `Failed to load the test bundle … different Team IDs`, тест-раннер и
тестовый бандл подписаны разными «командами». Подпишите всё своим бесплатным сертификатом
Apple Development (как получить Team ID — [Development.md §3](Development.md)):

```bash
make test-ui TEAM=ABCDE12345
```

## 4. Ручной чек-лист Phase 1

- [ ] `make run` — в строке меню появилась иконка, открылось окно JARVIS.
- [ ] Нет иконки в Dock.
- [ ] «Включить» → статус «Готов», в журнале «JARVIS включён»; «Выключить» → «Выключен».
- [ ] «Пауза микрофона» доступна только во включённом состоянии.
- [ ] Индикатор показывает «Микрофон не используется»; системного оранжевого индикатора нет.
- [ ] Privacy Mode в меню включается/выключается и отражается в журнале и в иконке щита.
- [ ] Настройки (⌘,): имя ассистента сохраняется после перезапуска.
- [ ] Автозапуск: переключатель появляется в «Системные настройки → Основные → Объекты входа».
- [ ] Журнал действий: записи есть, «Очистить…» удаляет их (и файлы в `audit/`).
- [ ] Испортить `settings.json` вручную → при запуске уведомление о восстановлении,
      в `backups/` есть копия испорченного файла.
- [ ] Ни один файл в `~/Library/Application Support/JARVIS` не содержит ничего, кроме
      настроек и событий журнала.
- [ ] Activity Monitor: JARVIS в простое ~0% CPU; записать фактический RAM в PerformanceTargets.md.

## 5. Ручной чек-лист Phase 2 (на твоём Mac)

Подготовка: `git pull`, `make run`, включить JARVIS.

- [ ] **Push-to-Talk.** Удержать ⌃⌥Пробел → появился запрос на микрофон → разрешить.
      Если появилась плашка «нужна языковая модель» — «Скачать модель», дождаться, снова удержать клавишу.
- [ ] Удерживая клавишу, сказать «Который час?», отпустить → звук «принял», ответ голосом и текстом.
- [ ] «Какое сегодня число», «Что ты умеешь», «Привет», «Спасибо» — разумные ответы.
- [ ] «Открой почту» → честное «научусь в следующей версии».
- [ ] Кнопка «Говорить» в окне: сказать команду, замолчать → команда выполнилась сама.
- [ ] Текстовое поле: «который час» + Enter → ответ текстом (без голоса).
- [ ] **Wake word.** Настройки → Голос → «Фраза-активатор». Появилась оранжевая точка микрофона.
      Сказать «Привет, Джарвис, который час» → ответ.
- [ ] Поговорить рядом 1–2 минуты без фразы-активатора → JARVIS не реагирует.
- [ ] Сказать «Привет, Джарвис» и замолчать → через ~6 с тихо вернулся в ожидание.
- [ ] «Привет, Джарвис, включи приватный режим» → щит в меню, запись в журнале с источником «Голос».
- [ ] «Привет, Джарвис, выключись» → JARVIS выключен, оранжевой точки нет.
- [ ] Пауза микрофона → оранжевая точка пропала.
- [ ] Вкладка «Личность»: юмор 0 → ответы без шуток; официальность 100% → на «вы».
- [ ] Язык English → «What time is it?» → ответ по-английски.
- [ ] Если распознавание не работает и появилась кнопка «Разрешить распознавание» — **напиши мне**,
      это ответ на открытый вопрос, нужно ли это разрешение.
- [ ] **Нагрузка** (сборка `make run-release`, цифры — внизу главного окна, через ~10 с в каждом
      режиме): PTT в ожидании; PTT, пока держишь клавишу и говоришь; wake word в тишине;
      wake word, когда рядом говорят. Повторить с моделью «Классическая» и «Новая модель Apple»
      (Настройки → Голос → «Модель распознавания»). Цифры — мне, я запишу в PerformanceTargets.md.
- [ ] **Где тратится процессор:** главное окно → раскрыть «Где тратится процессор», удерживать
      Push-to-Talk и говорить ~10 с → «Скопировать отчёт» → прислать мне. Повторить с выключенным
      «Показывать текст во время речи» (Настройки → Голос).
- [ ] **Тихая речь:** Настройки → Голос → «Чувствительность» 70–90 % → сказать команду тихо.
      Затем убедиться, что на 30 % JARVIS не реагирует на фоновый шум.

## 5a. Ручной чек-лист Phase 3a (на твоём Mac)

Подготовка: `git pull`, `make run-release`, включить JARVIS.

- [ ] «Открой Safari», «открой калькулятор», «открой настройки», «открой браузер» — открылось.
- [ ] «Переключись на Safari» при открытом Safari — окно вышло вперёд.
- [ ] «Открой ютуб» / «зайди на github.com» — сайт открылся в браузере.
- [ ] «Найди в интернете рецепт борща» — открылась страница поиска (Google; Яндекс — в
      Настройки → Основные → «Поиск в интернете»).
- [ ] «Громкость 30», «сделай громче», «потише», «выключи звук», «включи звук».
- [ ] «Закрой калькулятор» → вопрос «Точно закрыть «Калькулятор»?» и окно поверх всех окон.
      Ответь голосом «нет» → калькулятор остался. Повтори и скажи «да» → закрылся.
      Если macOS спросит разрешение «Автоматизация» — разрешить (это для закрытия приложений).
- [ ] То же кнопками: «Нет» (Esc) и «Да» (⏎). Крестик окна = «Нет».
- [ ] Ничего не отвечать 30 с → «Не дождался ответа — ничего не делаю».
- [ ] «Закрой Finder» → «закрывать не буду». «Закрой Telegram», когда он не запущен → «и так не запущено».
- [ ] Журнал действий: «apps.quit — выполнено/отменено», без текста команд.
- [ ] **«Привет, Джарвис» по кнопке «Говорить».** На экране остаётся «Привет, Джарвис» (не
      стирается), через ~2 с JARVIS отвечает приветствием. Одно слово «Джарвис» → «Слушаю.».
      «Джарвис, который час» → на экране вся фраза, ответ — время.
- [ ] **Микрофон Mac при надетых AirPods.** Настройки → Голос → Микрофон: встроенный микрофон
      Mac. Распознавание чёткое с первого слова, музыка в AirPods не теряет качество.
- [ ] **AirPods / Bluetooth-гарнитура.** Говорить — полоска уровня рядом с «Микрофон слушает»
      двигается. Если выбрать гарнитуру в настройках JARVIS и звука нет — через 3 с подсказка
      «Микрофон не передаёт звук…». С «Системный по умолчанию» + гарнитура в «Системные
      настройки → Звук → Вход» — JARVIS слышит.

## 6. Принципы

* Тесты не обращаются к сети и не трогают реальные данные пользователя (временные папки,
  флаг `--ui-testing`).
* Время в тестах — управляемые часы (`TestClock`), а не `Date()`.
* Каждая новая функция — с тестами; каждая найденная ошибка — с регрессионным тестом.
* Результаты не подгоняются: упавший тест чинится или честно документируется.
